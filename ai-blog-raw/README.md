# ai-blog-raw

발행하지 않는 원자료·작업 노트를 두는 자리입니다. 이 디렉터리의 내용은 **기본적으로 git에 올리지 않습니다** (`README.md`만 예외로 추적).

## 여기에 두는 것

- 공식 블로그·기사 등 **전문 번역 초안** (참고·대조용)
- 조사 중간 산출물, 원문 덤프, 스크랩 메모
- 공개 글 쓰기 전 재료

## 여기에 두지 않는 것

- 사이트에 올릴 최종 글 → `src/content/blog/`
- API 키, 계정, 개인 금융 수치 등 민감 정보 (로컬에서도 넣지 말 것)

## 공개 글 원칙 (참고)

공식 발표·타사 블로그를 다룰 때는 전문 번역 재게시보다 **핵심 요약 + 해설(+ 직접 조사분)** 으로 `src/content/blog/`에 발행합니다. 전문 번역은 이 raw 폴더에만 둡니다.
